# Original project branding

`mark.svg` and `logo.svg` are original Offline GitHub assets, licensed under the
repository's MIT license. The mark represents a local document archive with a
small lime status square. It contains no GitHub, Cezar, or Open Mercato logo.

The interface takes visual cues from Cezar / Open Mercato's neutral dark surfaces:

| Token | Value |
| --- | --- |
| Background | `#0d0d0d` |
| Sidebar and cards | `#171717` |
| Raised surface | `#1c1c1c` |
| Border | `#262626` |
| Foreground | `#fafafa` |
| Muted text | `#a3a3a3` |
| Accent | `#a8f372` |

The application and favicon use `web/public/brand/mark.svg`; keep its matching
copy here in sync. The README uses the full wordmark in `logo.svg`. All branding
is served locally. Status colors for errors, reviews and diffs remain semantic.
